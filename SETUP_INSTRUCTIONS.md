# 🚀 GitHub Profile Setup Instructions

This guide will help you set up your stunning GitHub profile with all the advanced features.

## 📋 Prerequisites

1. **GitHub Account**: Ensure you have a GitHub account
2. **Special Repository**: Create a repository with the same name as your GitHub username
3. **Repository Settings**: Make sure the repository is public

## 🔧 Setup Steps

### 1. Repository Creation
1. Create a new repository named exactly as your GitHub username: `Unseencoderz`
2. Make it public
3. Initialize with a README (you'll replace this with our custom one)

### 2. Upload Files
1. Copy the `README.md` content to your profile repository
2. Create the `.github/workflows/` directory structure
3. Upload the `snake.yml` workflow file

### 3. Enable GitHub Actions
1. Go to your repository settings
2. Navigate to "Actions" → "General"
3. Ensure "Allow all actions and reusable workflows" is selected
4. Save the settings

### 4. Repository Permissions
1. Go to "Settings" → "Actions" → "General"
2. Under "Workflow permissions", select "Read and write permissions"
3. Check "Allow GitHub Actions to create and approve pull requests"
4. Save changes

### 5. Run the Snake Animation Workflow
1. Go to "Actions" tab in your repository
2. Find "Generate snake animation" workflow
3. Click "Run workflow" to generate the snake animation manually
4. Wait for it to complete successfully

## 🐛 Troubleshooting

### Snake Animation Not Working
1. Check if the workflow ran successfully in Actions tab
2. Ensure repository permissions are correctly set
3. Verify the username in the workflow file is correct
4. Make sure the repository is public

### Stats Not Loading
1. Verify your GitHub username is correct in all URLs
2. Check if the external services (vercel.app) are accessible
3. Try refreshing the page after a few minutes

### Broken Images
1. Ensure all image URLs are accessible
2. Replace broken GIF URLs with working alternatives
3. Check if external services are online
